# MVP 개발 태스크 목록

## 개요

이 문서는 MVP 개발을 위한 최소 단위 태스크를 단계별로 정리한 것입니다. 각 태스크는 독립적으로 완료 가능하며, 1-2일 내에 완료할 수 있는 크기로 분할되었습니다.

---

## Phase 1: 프로젝트 설정 및 인프라 기반 구축

### 1.1 프로젝트 초기 설정

#### TASK-001: Spring Modulith 모듈 구조 설정
- **우선순위**: P0 (최우선)
- **예상 시간**: 4시간
- **설명**: 
  - Spring Modulith를 사용한 **단일 애플리케이션(Monolith)** 내 모듈 구조 생성
  - 모듈: `collection`, `processing`, `trading`, `risk`, `ai`, `api`
  - 각 모듈을 패키지로 분리 (예: `com.xijjun.trading.collection`)
  - 모듈 간 의존성 규칙 정의
  - `@Modulith` 어노테이션으로 모듈 구조 활성화
- **완료 기준**: 
  - 각 모듈이 패키지로 분리됨
  - 모듈 간 의존성 규칙 정의 완료
  - Spring Modulith 테스트로 구조 검증 통과
- **참고**: 
  - 단일 JAR 파일로 배포되는 Monolith 구조
  - 나중에 마이크로서비스로 전환 가능하도록 설계
  - 자세한 내용: `docs/architecture/MODULITH_STRATEGY.md` 참고

#### TASK-002: 데이터베이스 스키마 설계 및 마이그레이션
- **우선순위**: P0
- **예상 시간**: 6시간
- **의존성**: TASK-001
- **설명**:
  - Flyway 마이그레이션 파일 생성
  - 테이블 설계:
    - `candlesticks` (OHLCV 데이터)
    - `trades` (거래 이력)
    - `positions` (활성 포지션)
    - `risk_audit_logs` (리스크 검증 로그)
    - `trading_config` (트레이딩 설정)
  - 인덱스 설계
- **완료 기준**: 
  - 모든 테이블 생성 완료
  - 마이그레이션 실행 성공

#### TASK-003: 환경별 설정 파일 구성
- **우선순위**: P0
- **예상 시간**: 2시간
- **설명**:
  - `application-local.properties` 설정
  - `application-sandbox.properties` 설정
  - 환경 변수 기반 설정 구조
  - 바이낸스 API 키 설정 구조
- **완료 기준**: 
  - 환경별 프로파일 전환 가능
  - 민감 정보는 환경 변수로 관리

#### TASK-004: 기본 의존성 추가
- **우선순위**: P0
- **예상 시간**: 2시간
- **설명**:
  - `build.gradle.kts`에 필수 의존성 추가:
    - Resilience4j (재시도, 서킷 브레이커)
    - Spring Actuator
    - Logback (JSON 로깅)
    - 바이낸스 API 클라이언트 (또는 HTTP 클라이언트)
  - 의존성 버전 관리
- **완료 기준**: 
  - 프로젝트 빌드 성공
  - 모든 의존성 다운로드 완료
